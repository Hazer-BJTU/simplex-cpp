# Model providers

## Provider configuration

Choose the guide for the plugin installed on your worker:

- [DeepSeek](deepseek.md) — DeepSeek thinking controls and reasoning replay.
- [Qwen](qwen.md) — Qianwen AI text and vision models, thinking budgets and tool calls.
- [GLM (Zhipu AI)](glm.md) — BigModel endpoints and GLM-5.3 generation controls.
- [Custom Chat Completions](chat-completions.md) — streaming endpoints with configurable message, request, response and usage rules.

The adaptation date on each guide identifies the documented plugin revision's
review date. Consult the linked service documentation for current account
availability. The source tree also includes a separate `openai` Responses
adapter. The four guides above cover Chat Completions integrations.

For fields shared by these profiles, see [worker configuration](../getting-started/configuration.md#provider-fields).
