# simplex-cpp
Lightweight C++ based LLM agent framework &amp; application as learning project.


The installed command entry point is `simplex`:

```sh
simplex --help
simplex run --config ./config.yaml --session demo --threads 4
```

See the [worker guide](core/README.md) for configuration and the
[hub guide](hub/README.md) for the interactive server and browser panel.
